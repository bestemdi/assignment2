# Анализ датасета RFSD

Учебная работа по промежуточной аттестации 2. Анализ выполнен с помощью Pandas, matplotlib и seaborn.
Выполнила Яковлева Дина

## Выполненные пункты

- До начала анализа отобраны ровно 20 признаков + 2 (оставили ИНН для идентификации компаний и регион) и 1000 строк.
- Выполнена подготовка числовых признаков и анализ пропусков.
- Рассчитана описательная статистика.
- Построены гистограммы для `age` (возраст), `PL_revenue` (выручка) и `PL_net_profit` (чистая прибыл).
- Для выбранных показателей рассчитаны выбросы по правилу 1,5 IQR.
- Построена матрица корреляции для всех 20 выбранных колонок.
- Отдельно посчитаны пары с корреляцией >= 70%.
- Построена диаграмма рассеивания для наиболее коррелирующей пары (Assets (совокупные активы) и Current Assets (оборотные активы)).
- Под каждым графиком добавлена интерпретация.
- В конце описаны краткие итоги и проведён небольшой доп. анализ по выборке.
